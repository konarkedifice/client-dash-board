Google Drive — simple connection

Use your dedicated KONARK EDIFICE folder. The first setup requires deploying the companion Apps Script file once; after that, this app can save and restore a JSON snapshot in that folder. Automatic sync runs after local saves while this app is open.

Google Drive is not connected. Configure the Web app URL and shared key first.

This is cloud snapshot sync, not a transactional real-time database. Automatic upload works only while the app is open and a provider is configured. Use Sync now / Restore from cloud to retrieve updates on another device; avoid simultaneous edits because last-write-wins can overwrite changes.

Optional OneDrive connection (advanced)

OneDrive remains available for users who already have a Microsoft Entra app registration. This requires a client ID and is not needed for Google Drive.

Manual backup & restore

Backup includes clients, projects, quotations, invoices, milestones, payment allocations, receipts, expenses, numbering counters and settings. It does not include the separate V1.0 dataset.

Restore validates the file and asks for confirmation. A recovery copy of current data is downloaded before replacement when current records exist.
